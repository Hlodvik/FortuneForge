# FortuneForge original themed audio, version 1

Seventeen title-specific suites retain twenty original Ogg Vorbis cues each. Neon Nights retains its exact approved PCM source composition. The other sixteen suites have distinct instrument palettes, motifs, scales, harmonies and rhythms fitting their titles.

Neon also has one additional `win-nice-v1.ogg` human voice callout. It replaces Neon's low/premium/five-symbol/777 paid-win stingers with a single short “NICE!” at a recommended gain of 0.58; the original stingers remain as unused source assets. The recording is Sadiquecat's “Joyful - Nice 2,” released under CC0, with local EQ, compression and quiet slap delay. See [the runtime source note](neon-nights/WIN-NICE-SOURCE.md) for the creator page, license, hashes and processing. Neon's other cues and music retain their existing selection. The original-synthesis declaration applies to the baseline twenty tracks per suite, not this added human recording.

Arcane Archives selects one additional CC0 loop, MintoDog's `magic-puzzle-in-game-1.ogg`, for its active music. It continues through bonus rounds at a 0.28 base gain. Its generated `night-drive.ogg` and `midnight-mix.ogg` remain as inactive source assets. See [the Arcane music source note](arcane-archives/MAGIC-PUZZLE-SOURCE.md) for the creator page, license and source hash. The original-synthesis declaration applies to Arcane's baseline twenty tracks, not this added recording.

Runtime URL: `/assets/slots/audio-suites/v1/{slug}/{cue-id}.ogg`. The manifest at this directory and each title's `manifest.json` provide all URLs, loop flags, recommended playback gains, measured source/decoded levels, durations, content hashes and source provenance. Generic collection cue filenames are shared identifiers; each suite provides its own four differentiated sounds.

Reproducible baseline source: `tools/audio-suites/render-themed-suites.mjs`. Original PCM masters remain in `output/artwork/themed-slots-audio-2026-11-02/masters`, with approved Neon masters at `output/artwork/neon-nights-2026-11-02/audio-suite-v1`. The added callout's processed master and export record are in `output/neon-payline-review-2026-11-02/nice-audition`. Baseline runtime assets are pre-rendered 44.1 kHz stereo, Vorbis quality 5. Every baseline file is decoded and checked during rendering. Midnight Vault, Wukong and Pirates retain their existing audio and are excluded.
