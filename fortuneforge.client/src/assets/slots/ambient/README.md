# Slot ambience credits

The MP3 files in this directory are sourced from [DOVA-SYNDROME](https://dova-s.jp/en/). They are used as low-volume, looping in-game background music after a player begins a spin. Their [Audio Asset Use License](https://dova-s.jp/en/help/articles/license-usage/) permits use as paid or free game background music, including commercial use, and permits editing and looping.

Each file keeps its source title so a future maintainer can verify the track page and creator-specific notes:

- `ancient-sword.mp3` — [An Ancient Sword (DOVA 23147)](https://dova-s.jp/en/bgm/detail/23147)
- `asian-dragon.mp3` — [Asian Dragon (DOVA 19980), Merry bad ending](https://dova-s.jp/en/bgm/detail/19980)
- `carnival-lights.mp3` — [Carnival (DOVA 12606), Yosame Yu](https://dova-s.jp/en/bgm/detail/12606)
- `casino-rock.mp3` — [Casino de Rock (DOVA 18657)](https://dova-s.jp/en/bgm/detail/18657)
- `country-trail.mp3` — [Wagon Wheel Jazz (DOVA 23708)](https://dova-s.jp/en/bgm/detail/23708)
- `cyber-night.mp3` — [Cyber-style BGM (DOVA 8334), TAKAO Masaki](https://dova-s.jp/en/bgm/detail/8334)
- `desert-wind.mp3` — [Swirling desert wind (DOVA 23035)](https://dova-s.jp/en/bgm/detail/23035)
- `forest-journey.mp3` — [A Journey in the Forest (DOVA 23670)](https://dova-s.jp/en/bgm/detail/23670)
- `haunted-chimes.mp3` — [Horror chime ambience (DOVA 21024), Aisyu](https://dova-s.jp/en/bgm/detail/21024)
- `nordic-atmosphere.mp3` — [Nordic Atmosphere (DOVA 20973)](https://dova-s.jp/en/bgm/detail/20973)
- `pirate-voyage.mp3` — [Pirate Ship Dungeon (DOVA 21763), KK](https://dova-s.jp/en/bgm/detail/21763)
