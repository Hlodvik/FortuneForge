# Card audio

Six small interface sounds shared by card-game clients. They were selected from
Kenney's **Casino Audio 1.1** pack: card shuffle/place/slide and chip lay/handle/collide.
The original `License.txt` is retained beside the files; all clips are CC0.

Source: https://kenney.nl/assets/casino-audio

Use the semantic cues `shuffle`, `deal`, `move`, `chip`, `collect`, and `click`.
Clients should trigger them only in direct response to a user gesture and must
silently tolerate browser audio-policy rejection.
