# `@fortuneforge/games-snake`

Reusable Snake React client and HTTP gateway. For a local preview:

```powershell
cd games/Snake/client/FortuneForge.Games.Snake.Client
npm install
npm run dev
```

Open `http://127.0.0.1:5184`. The development host uses the real deterministic Snake engine at `http://127.0.0.1:5194`.
