## Chosen reference: OneTouch emerald digital table

The implementation closely follows its material palette, curved table edge, centered title, three-pile arrangement, recessed gold card outlines, chip control row and immediately adjacent edit/deal controls. It uses responsive portrait and short-landscape arrangements to retain the same game hierarchy.

Original changes serve this requested variant: explicit Andar-first 0.9:1/Bahar 1:1 labels, main bets only, one selected side, result overlay with net accounting, server-confirmed replay/recovery, and FortuneForge navigation/wallet composition at integration. TaDa's avatars/dealer and all providers' side bets were intentionally outside the requested solo scope.

No reference screenshot or provider asset is used as a product asset. The generated material prompt and source paths are recorded in [ASSETS.md](ASSETS.md).
