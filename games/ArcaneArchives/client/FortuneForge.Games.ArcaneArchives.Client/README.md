# ArcaneArchives slot client

Standalone browser-owned presentation package for the ArcaneArchives slot game.

This package owns its manifest, catalogue metadata, symbols, cabinet
configuration, styles, audio contract and in-game media. Authentication,
wallet settlement, Firebase hosting and the shared Fortune Forge navbar remain
host responsibilities.

## Payline rules

Exactly three identical symbols in a straight row or diagonal can start on
reels 1, 2 or 3. Five identical symbols pay on any of the existing full paylines.
