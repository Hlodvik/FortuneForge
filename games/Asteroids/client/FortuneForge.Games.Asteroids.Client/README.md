# `@fortuneforge/games-asteroids`

Reusable Asteroids React client and HTTP gateway. The preview intentionally renders ships, asteroids, bullets, stars, and thrust flames with canvas primitives so an art-backed renderer can replace it later.

```powershell
cd games/Asteroids/client/FortuneForge.Games.Asteroids.Client
npm install
npm run dev
```

Open `http://127.0.0.1:5188`. The development host uses the real deterministic Asteroids engine at `http://127.0.0.1:5198`.
