# Pharaoh’s Ascent

Pharaoh’s Ascent replaces Cosmic Fortune in the catalogue. Its public paid route is `/slots/pharaohs-ascent`. The historical package, wallet and persistence identifiers remain `cosmic-fortune` / `cosmic-fortune-v1` so existing paid records and pending operations remain recoverable.

The client owns `PharaohAscentGame`, `PharaohAscentView`, its controller, validated API boundary, audio, cabinet artwork, guide and Sealed Tomb interaction. Its browser release starts at `src/browser.ts`; it does not render through the host’s generic slots page. The platform supplies account data, authenticated HTTP and optional navigation chrome. Neutral widgets, audio and animation primitives are shared packages.

## The Sealed Tomb

Two or more red scarabs on a normally charged spin earn one funded sigil. Six sigils form an expedition ticket at their average wager. Existing earned reel spins finish before a ticket can be used.

An expedition begins with six torches and a secured reward of 5× its funded stake. Every chamber adds a reward. Players choose coins, a visible relic, or a key. Complete Sun/Moon/Serpent sets multiply all room prizes, including earlier rooms. Three keys unlock an additional sarcophagus award. The player can collect while exploring; the last torch settles automatically. Entry and sarcophagus prizes remain separate from relic multipliers.

The production server owns choices, random outcomes, funds, saved state and settlement. Expedition actions share the same paid operation store and account lock as reel spins. Retries preserve operation identity and settle once. Exact RTP calibration is deferred for this local review version.

## Local review

The review runs the same production game and settlement code with an isolated Firestore emulator project, local test account and test wallet. It has no public demo mode, forced bonus controls or alternative outcome engine.

1. Start a loopback Firestore emulator, then set `FIRESTORE_EMULATOR_HOST` to its address (the current session uses `127.0.0.1:8873`).
2. From the repository root, run `dotnet run --project games/CosmicFortune/tests/FortuneForge.Games.CosmicFortune.LocalHarness`.
3. Run `npm run review:local --workspace @fortuneforge/games-cosmic-fortune`.
4. Open <http://127.0.0.1:5176/slots/pharaohs-ascent>.

The harness binds only to `127.0.0.1:5301`, requires an emulator, and creates a separate `demo-pharaoh-paid-*` project. The review client refuses an API without the local/test-funds health contract. The review entry lives outside shipped `src` and `dist` files.

## Verification

- `npm run check --workspace @fortuneforge/games-cosmic-fortune`
- `npm run build --workspace @fortuneforge/games-cosmic-fortune`
- `npm test --workspace @fortuneforge/games-cosmic-fortune` runs the package-owned client tests.
- `npm run verify:standalone --workspace @fortuneforge/games-cosmic-fortune` builds the browser module and checks its emitted module graph for host, foreign-game and generic-screen dependencies.
- With the two local servers above running: `node node_modules/@playwright/test/cli.js test --config games/CosmicFortune/client/FortuneForge.Games.CosmicFortune.Client/playwright.config.ts`.

Game tests cover progression, connected scarabs, action rules, settlement, persistence, retries and historical replay. Browser evidence is saved under `output/artwork/pharaohs-ascent/browser`.

## Artwork and audio

Original raster artwork was created with the built-in imagegen tool. The exact prompt set is in `artwork/prompts.json`, original PNGs in `artwork/source`, and optimized delivery assets in the client’s `src/assets/art/pharaohs-ascent`. `artwork/prepare-pharaoh-art.mjs` reproduces the delivery crops and WebP exports.

The package’s original procedural Egyptian audio is generated by `client/FortuneForge.Games.CosmicFortune.Client/scripts/generate-pharaoh-audio.mjs`; its audio manifest records the generated files and hashes. The help payline layouts are generated from the authoritative C# game definitions.

No deployment is authorized until the user reviews and explicitly approves the game.
