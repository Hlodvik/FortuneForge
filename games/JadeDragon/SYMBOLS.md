# Jade Dragon backend identifiers

Symbol values are opaque IDs. The backend exposes no display names or assets.
Clients and game builders assign their own presentation without changing these
IDs. Inspect `JadeDragonEngine.SymbolMetadata` for machine-readable roles,
payline payout rules, strip eligibility, value multipliers and track bindings.

| IDs | Backend role | Current behavior |
| --- | --- | --- |
| S01–S06 | Payline | Ordinary paying symbols. The embedded paytable defines multipliers. |
| S07 | Wild | Pays native runs of 3 or 5; substitutes in runs of 5. Feature spins may inject two. |
| S08 | Scatter | Three visible symbols award 6 spins. Frequency filtering keeps each generated occurrence with probability 1/2. |
| S09 | Special points | Exact native matches of 3 or 5 award 1 or 2 special points. Also has payline payouts. A boost costs 8 special points. |
| S10 | Meter | Retained in stored strips but excluded from playable strips while the meter is disabled. |
| S11 | Pattern | Three-symbol straight patterns pay 3 × wager before game scaling and integer rounding. Injected after base generation. |
| S12 | Collector | Defined backend role; not generated by the current rules. |
| S13–S19 | Value | Multipliers 0.5, 1, 1.5, 2, 3, 4, 5 respectively; not generated by the current rules. |
| S20 | Collection | Advances track1. |
| S21 | Collection | Advances track2. |
| S22 | Collection | Advances track3. |
| S23 | Collection | Advances track4. |

Each collection reaches its trigger at 22 and awards 8 `copy-expand-wild`
spins. That mode copies one randomly selected reel to another, expands the
visible grid by two rows, and injects two S07 symbols where eligible. The
ordinary grid has five reels, four rows and 23 paylines. Base wagers run from
2 to 2000 points in steps of 2. The payout scale is 0.866; monetary conversion
and balance ownership remain the host's responsibility.

To customize rules, edit the embedded definitions and game-owned policy code,
update the engine version, and run the backend tests. To customize appearance,
build a separate client mapping these IDs to presentation assets. No such
mapping or client is included here.
