# Midnight Vault browser client

This package owns the complete Midnight Vault browser experience: its controller,
HTTP response validation, bonus-round state, presentation, help and paytable,
symbols, audio and route-loaded media. The Fortune Forge application supplies
only the signed-in account, authenticated transport and shared application shell.

The public game and model identities remain `dragon-hoard-v1` and the existing
`midnight-vault-*` IDs for saved-round and audit compatibility.
